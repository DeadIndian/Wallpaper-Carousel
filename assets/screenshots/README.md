# Screenshots

Drop the images the README references here, then commit them:

| File | What to capture |
|---|---|
| `hero.png` | The picker open over a desktop — the money shot for the top of the README and the store listing. |
| `carousel.png` | Close-up of the bottom-centered carousel with a few thumbnails and the highlighted item. |
| `reveal.png` | Mid-frame of the expanding-circle reveal animation, ideally caught partway through. |

Use `spectacle` (Plasma's screenshot tool) or any capture tool. Keep them PNG,
reasonably sized (the README displays at 80–100% width). store.kde.org and Discover
both want real HTTPS-reachable images, so committing them here is what makes them show
up everywhere.
