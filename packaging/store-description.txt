--- DESCRIPTION (the store accepts basic markup; plain text is safest) ---
KDE's built-in slideshow wallpaper, with one addition: an external tool can write
the "Image" config key to jump the slideshow to a specific picture, and the
rotation timer keeps running from there.

It also records the slide it is currently showing, and which monitor it is on, so
another program can read back what is on screen right now instead of guessing.

Everything else behaves exactly like the stock Plasma slideshow: the same folder
list, ordering modes, fill modes, blur and solid-colour backgrounds, dynamic
day/night wallpapers, and the same Next Image action on the desktop context menu.

What it does
- Drop-in replacement for the stock Plasma slideshow wallpaper.
- Accepts an externally written image, mid-rotation, without a restart.
- Publishes the slide currently shown and the screen it is on, per desktop.
- Keeps the stock configuration UI, so nothing you already know changes.

For the best experience, install the Wallpaper Carousel app
This wallpaper is the receiving half of a pair. On its own it is the stock
slideshow. Install the app and you get a keyboard-driven carousel of thumbnails,
bound to a shortcut, that sets any image on any monitor and animates the reveal:

    https://github.com/DeadIndian/Wallpaper-Carousel

Fedora users can install both halves at once from COPR (see the README).

Requirements
- KDE Plasma 6 (tested on Plasma 6.5) with plasma-workspace installed.
- Nothing to compile. The wallpaper itself is pure QML.
- The Wallpaper Carousel app is optional, and needs a separate build or the COPR
  package.

Install
- Right click the desktop, Configure Desktop and Wallpaper, Wallpaper type,
  Get New Plugins, then search for "Carousel Slideshow".
- Or grab org.wallpapercarousel.slideshow-0.1.0.tar.gz from the release page and run:
      kpackagetool6 --type Plasma/Wallpaper --install org.wallpapercarousel.slideshow-0.1.0.tar.gz
  then pick Carousel Slideshow as the wallpaper type.
